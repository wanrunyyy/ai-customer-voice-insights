# 面试展示材料（建议 5 页）

1. **为什么做**：电商评论多且非结构化，人工逐条阅读耗时；业务想更系统发现共性问题。
2. **你的 AI 工作流**：真实数据→清洗→200条定向抽样→ChatGPT分类（固定Prompt）→Python验证→人工复核→可视化。
3. **核心发现**：报告中的实际Top 3主题（真实数量 + review_id 原始评论证据）。不得预先虚构。
4. **跨职能建议**：产品/运营/市场各1个待验证动作及衡量指标。
5. **局限和下一步**：定向抽样不代表总体；英文服装数据不代表国内腾讯用户；提升准确性可增加多标签和迭代抽检；后续可接入真实授权企业数据。

## STAR 面试故事骨架
- S：用户评价信息量大，手工判断不够系统。
- T：快速验证 AI 是否能辅助归类评论并提炼业务机会。
- A：独立确定分类标准和采样方案；编写ChatGPT提示词与Python验证脚本；抽检模型结果；制作Streamlit展示。
- R：如实报告已分析行数、人工一致率、发现的主题与可交付物。未真实测试的指标不写为业绩。
